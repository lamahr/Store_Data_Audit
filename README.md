# Проектный практикум по кейсу 2: Продажи и факторы динамики выручки в розничной торговле
Рабочее название проекта: «Что двигает продажи: факторы выручки розничной сети».

**Задача:** объяснить динамику недельных продаж 45 магазинов (тренд, сезонность,
праздники, markdown-акции, макропоказатели) и дать обоснованные рекомендации
по планированию промо.

**Результат:** аналитический отчёт и презентация для экспертов.

**Контрольные точки:** [форма проектирования](https://docs.yandex.ru/edit/disk/disk%2F%D0%97%D0%B0%D0%B3%D1%80%D1%83%D0%B7%D0%BA%D0%B8%2F%D0%A4%D0%BE%D1%80%D0%BC%D0%B0%20%D0%BF%D1%80%D0%BE%D0%B5%D0%BA%D1%82%D0%B8%D1%80%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D1%8F%20%D0%BA%D0%BE%D0%BC%D0%B0%D0%BD%D0%B4%D1%8B%20%E2%84%964.xlsx?source=docs)

## Приоритетные направления и гипотезы (утверждены с заказчиком)
1. **H1 — Эффективность промо-акций (MarkDown1–5):** связь проведения акций с увеличением выручки вне праздничного фона (IsHoliday == False) и различие вклада отдельных каналов промо *(подтверждена с уточнением дизайна проверки: +74.34% к медианной выручке при высоком промо-бюджете, p < 0.0001)*.
2. **H2 — Сезонные и праздничные пики:** изменение спроса в течение года, в праздничные периоды и постпраздничные 1–2 недели *(опровергнута по бизнес-порогу MDE на уровне всей сети из-за эффекта смешения отделов)*.
3. **H3 — Различия между форматами магазинов:** влияние типа (Type A/B/C) и площади (Size) магазина на относительный прирост выручки от промо и праздников *(опровергнута: относительная реакция в % статистически не различается по форматам)*.

*Отложенные направления (по согласованию с заказчиком):* углублённый анализ возвратов (`Weekly_Sales < 0`), макроэкономика и погода (`CPI`, безработица, топливо, температура), поведенческая кластеризация отделов.

Источник: [Retail Data Analytics](https://www.kaggle.com/datasets/manjeetsingh/retaildataset).
